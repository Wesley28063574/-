雲端尚未連接。網站的活動紀錄與同步程式已準備好，先由你建立公司自己的 Supabase 專案，再完成下列設定。

先完成：建立帳號與專案

  1. 開啟 Supabase 註冊頁，用公司信箱或你負責管理的帳號註冊、登入。

  2. 建立 Organization（組織），名稱可填「50嵐活動系統」。先選頁面提供的 Free 免費方案，不需先升級付費。

  3. 選 New project，名稱填「Lansatar Activities」。資料庫密碼由你設定並自行保管，不需要提供給對話助手。地區選亞洲區，例如東京或新加坡。

  4. 等待專案建立完成，回到對話告訴我「專案建立好了」，再接續資料表與主持人帳號設定。

專案完成後：建立私人活動資料庫

在專案的 SQL Editor 新增查詢，貼上準備好的設定檔執行。這會建立活動紀錄、主持人名單與私人照片儲存空間。
