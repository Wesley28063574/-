# 活動後台與雲端設定

目前公開網站使用 IndexedDB，活動資料留在目前瀏覽器，並非已上線的雲端後台。跨電腦保存的程式與 SQL 已備妥；尚未配置雲端專案與主持人帳號，未驗證實際 Supabase 服務端部署。

## 可使用的本機功能

- 進入遊戲會自動建立未命名活動，後台可補活動名稱、日期、學校、地點、年齡、主持人、人數及備註。
- 後台可建立2–6組的獨立活動；每場凍結題目版本，保存答案、分數、合照、漫畫圖、分享重點、閉店會議與操作變更紀錄。
- 自動保存、重新整理後恢復、繼續活動、結束封存、搜尋、完整JSON匯出／匯入。備份含照片，請妥善保管。
- 分享重點與會議決議須由主持人輸入，不會自動錄音或轉錄。
- 同一場活動由一個遊戲視窗操作；不要同時在兩個視窗編輯。偵測到另一視窗更新時會停止覆蓋。
- 清除網站資料、無痕模式或換電腦無法保證保留本機紀錄。請每場結束匯出JSON備份；瀏覽器儲存失敗會顯示錯誤。

## 啟用真正的雲端保存

1. 在公司的 Supabase 帳號建立專案，執行 supabase.sql（首次安裝一次）。
2. 關閉公開註冊，透過 Auth 管理建立主持人帳號，再將核准 UUID 加入 activity_staff。
3. 在 assets/cloud-config.js 填入專案 URL 與公開 anon/publishable key。這些不是管理密鑰；不可填 service_role。
4. 發布網站後，後台登入主持人帳號。資料與照片只允許名單內帳號存取；照片放在私人 bucket，其他訪客不能讀取。
5. 使用兩個瀏覽器實際驗證：登入、建立活動、題目／照片同步、異機讀取、登出阻擋與版本衝突。完成驗證後才可稱為雲端正式上線。

雲端與本機的未同步版本衝突時保留本機，不會靜默覆蓋；應先匯出備份再確認紀錄。所有主持人屬於同一家公司名單，可共同讀取活動。不要把 JSON、學生合照或雲端登入密碼提交到公開 Git 儲存庫。
